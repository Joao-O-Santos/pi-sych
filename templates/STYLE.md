# Style

State applicable prose, documentation, code, presentation, and testing conventions.

Style sources follow package `style-application` precedence: explicit user instruction, this file, approved project profile, private user style, artifact or genre defaults, then package writing defaults.

## Package defaults in force unless overridden above

- Prose Markdown hard-wraps at 72 columns; do not hard-wrap code fences, tables, or unsplittable URLs.
- Prefer claim–support–consequence paragraphs, explicit topic sentences, and concrete wording.
- Titles foreground a surprising or consequential intellectual move without clickbait.
- Voice follows information focus; active voice is not a blanket rule.
- Reveal.js talks use the white theme, no transition, 16:9 layout, minimal incremental reveals, level-one slide titles, and a **project-local copy** of the packaged Reveal baseline CSS once that file has been copied into the project.
