# Argument-analysis examples

## Rival explanation is not automatically a fallacy

Claim:

> Training caused the higher scores because trained participants scored higher.

Map:

- premise: trained participants had higher observed scores;
- inference: the score difference was caused by training;
- unstated assumption: assignment and measurement exclude material common
  causes;
- rival: prior ability affected both training uptake and scores;
- discriminator: random assignment or credible adjustment using pre-training
  ability.

The rival shows underdetermination. It is not by itself a named logical
fallacy, and it does not prove that training had no effect.

## Weak premise versus overbroad scope

Bad:

> The citation is old, so the argument is invalid.

Better:

> First ask whether the source still supports the premise. Separately ask
> whether the conclusion generalizes beyond the source population. Weak premise
> support and missing scope conditions are different defects.

Why:

Each diagnosis has a different consequence and repair.
