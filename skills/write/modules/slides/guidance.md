# Slides

Venue, accessibility, and project style override these defaults. Give each slide one communicative job; use hierarchy and speaker-appropriate detail instead of paragraph walls. Use the rendering stack named by project conventions or user machine context (STACK.md); if nothing available can render, report that; source is not a rendered deck. Do not copy personal logos, assets, or private themes without explicit user provision. Inspect the actual render for figures, code, citations, reveals, labels, contrast, and essential alt text or spoken equivalents. Check timing and cut slides before shrinking type.
