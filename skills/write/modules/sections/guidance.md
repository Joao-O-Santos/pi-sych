# Sections

Generic paragraph and section mechanics live with the [prose method](../../../_methods/prose/guidance.md); read it first when the sequence or paragraph jobs are unclear.

For an abstract state the problem, approach, contribution or result, and
implication without adding content. An introduction establishes the problem and
intellectual move. Methods make consequential design and analysis decisions
inspectable. Results report the supported pattern without importing discussion.
Discussion synthesizes rather than repeats, considers serious alternatives,
states concrete limits and next tests, and ends with a calibrated take-home. A
conclusion should resolve the artifact's job rather than add a generic
importance claim.

Calibrate voice, format, citation practice, and explanation to audience and
genre. Preserve citations, placeholders, uncertainty, and authorial variation.
Use titles and headings to expose the sequence without clickbait or mechanical
road-map prose. Follow the project's Markdown and renderer configuration when it
applies. Run a formatter and inspect its diff before reporting formatter work;
do not add a dependency solely for prose formatting.
