# Retrospective

Propose; do not mutate. Separate observed events and actual verification from interpretation. Prefer local lessons; require repeated evidence or an obvious structural defect before proposing a general rule. For each candidate state observed evidence (including commands/artifacts), repetition or structural basis, smallest candidate lesson, alternative explanation, proposed local target (or none), and human decision (accept, modify, defer, or reject). Do not mine unattended transcripts, create global memory, edit package state, or commit automatically.
