# Status

First call `project_status` with `action: "check"`. Changed hashes, missing files,
and declared dependents are mechanical facts only. Inspect the changed files and
relevant dependents before calling disagreement or drift.

If the required resolution is already covered by an explicit owner instruction
or accepted project direction, complete that work and then acknowledge only
named files actually reviewed. Acknowledgement records reviewed state, not correctness, and may
leave dependents needing review.
