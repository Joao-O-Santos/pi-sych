# Git

Inspect working tree, branch, and relevant history before changing refs.
Follow the repository's local branch, commit, merge, and release conventions.
Do not push, publish, open a pull request, alter remotes, rewrite shared
history, delete branches, or tag without explicit instruction. Make coherent
verified commits only when the repository convention calls for them.

Use a concise imperative subject and the repository's established message
format. Before merging confirm intended commits and target; preserve shared
history. A private unpushed branch may be rebased only when the repository's
conventions and the task permit it.

For rewrites confirm targets, relationships, working tree, and remote
implications. Never rewrite shared or pushed history automatically. Prefer the
simplest supported operation; do not create branch policy or process theatre
for a small change.
