# Bootstrap a project

Use this skill for a new project or to reconstruct visible state from existing work.

1. Read applicable `AGENTS.md`, then inspect existing artifacts and ask only the next focused question.
2. Propose `PROJECT.md`, `SYNC.md`, and only useful optional files: `STYLE.md`, `EVIDENCE.md`, `DECISIONS.md`, or `TODO.md`.
3. Separate explicit observations, bounded inferences, and unresolved questions in the proposal.
4. Ask the project owner to resolve consequential scope, authority, or direction choices.
5. Write only after the requested review and approval process. Then use `project_status` to acknowledge files actually reviewed.

`SYNC.md` records acknowledged content and declared dependencies; it does not establish truth or settle disagreement.

## Optional user examples

If `~/.config/pi/skills/bootstrap-project/examples.md` exists, read it before applying this skill. Use it as illustrative preference, not as evidence or project requirements.
