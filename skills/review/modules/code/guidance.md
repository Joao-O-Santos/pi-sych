# Code

Review correctness, maintainability, failure handling, interfaces, tests, plausible security implications, and unnecessary complexity. Trace findings to a reachable behavior, changed contract, or concrete maintenance burden; distinguish defects from optional design preferences. Check error paths, boundary conditions, state transitions, compatibility, and whether new machinery has a demonstrated need. State the consequence, bounded repair, and uncertainty. The review is advisory and never silently creates approval or an architectural mandate.
