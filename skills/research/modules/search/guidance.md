# Search

Decompose the question into answerable subquestions, inspect local material, choose proportionate queries and source types, iterate deliberately, and state a stopping rule. Record query terms, databases or collections, date boundaries, and retrieval failures when they affect coverage. Use search results for discovery, not proof; compare sources rather than treating the first plausible result as decisive. Retrieval access does not establish completeness, so report material time-window, terminology, or coverage gaps.
