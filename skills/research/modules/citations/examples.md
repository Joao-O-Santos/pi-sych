# Citations examples

## Secondary quotation

Input: a quotation is attributed to a secondary source.

Output: locate the original where possible, verify wording and surrounding
context in the inspected source, and cite the source that supports the exact
claim. Metadata can help locate the original but cannot verify the quotation.

## Metadata conflict

Input: two services disagree about year, DOI, or version.

Output: use the discrepancy to trigger targeted verification against the
publisher, DOI record, repository, or inspected document. Record the version
actually used rather than silently choosing whichever metadata service appeared
first.

## Citation supports only part of a sentence

Input: a source supports the empirical result but not the broad causal
interpretation attached to it.

Output: narrow or split the claim, preserve the supported result, and mark the
causal interpretation as inference or unsupported rather than allowing a
correctly formatted citation to carry both.
