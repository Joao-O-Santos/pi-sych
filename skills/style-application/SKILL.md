# Style application

This skill is the canonical style-precedence source for the package. Genre
skills and templates should refer here rather than restate a partial order.

Apply style in this order:

1. explicit user instruction
2. project `STYLE.md`
3. approved project profile
4. private user style overlay
5. artifact-local renderer or venue requirements (for example talk metadata,
   journal rules, accessibility constraints)
6. artifact or genre defaults
7. package `writing-core` and other package defaults

State the active source when it matters. Package defaults such as 72-column
prose wrapping, claim–support–consequence paragraphs, concrete wording,
provocative-but-honest titles, and Reveal visual defaults apply only when no
stronger source governs them. Preserve genre-specific variation and report
drift as concrete local fixes rather than rewriting an artifact into a generic
house style.

## Sentence-level judgment

Do not treat active voice as a universal improvement. Following the Pullum
critique of blanket anti-passive advice, choose voice according to information
focus:

- Use passive when the acted-on entity, event, or method should occupy the
  reader's attention, or when the actor is obvious, irrelevant, or unknown.
- Use active when a specific actor's agency matters to the claim, responsibility,
  or causal account.
- Repair repeated agentless passives only when they hide who did what; do not
  mechanically convert a clear methods sentence merely because it is passive.

Likewise, use topic-to-comment flow, early main actions, end-weight, concrete
terms, and consistent terminology as diagnostic preferences rather than rigid
rules. Preserve deliberate rhythm, emphasis, dialect, accessibility choices,
and authorial variation unless they obstruct the artifact's purpose.
